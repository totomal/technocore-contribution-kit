# Technocore Contribution Kit

Technocoreへの貢献内容を、日本語・英語で整理するコミュニティツールです。

## できること

- 貢献内容の説明文を作成
- 日本語・英語の投稿文を作成
- X投稿の下書きを作成
- 活動ログをMarkdownで作成

## 重要

このプロジェクトはFLOP Labs公式ではありません。

エアドロップ、報酬、トークン配布、選考を保証しません。

秘密鍵、シードフレーズ、パスワード、APIキーは入力しないでください。
