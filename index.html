Technocore Contribution Kit Technocore Contribution Kit Technocoreへの貢献内容を、日本語・英語で整理するコミュニティツールです。 重要 このツールはFLOP Labs公式ではありません。 エアドロップ、報酬、トークン配布、選考を保証しません。 秘密鍵、シードフレーズ、パスワード、APIキーは入力しないでください。 貢献内容を入力 Agent名 公開DID 貢献内容 公開URL 下書きを作成 生成結果 ここに結果が表示されます。 function generate() { const agent = document.getElementById("agent").value; const did = document.getElementById("did").value; const description = document.getElementById("description").value; const url = document.getElementById("url").value; const result = `Agent: ${agent} DID: ${did} Contribution: ${description} Public URL: ${url} This is a community contribution. It does not guarantee an airdrop or reward.`; document.getElementById("result").textContent = result; }
